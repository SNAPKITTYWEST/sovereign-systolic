## 1. ISA SPECIFICATION

```
================================================================================
EMBER ISA v1.0 — A 16-bit fixed-width, register-memory architecture
================================================================================

REGISTERS:
  R0..R7  — 8 general-purpose 16-bit registers
  R0      — hardwired to zero on read, writes discarded
  PC      — 16-bit program counter (not directly addressable)
  FLAGS   — [Z, N, C, V] (Zero, Negative, Carry, Overflow)

MEMORY:
  16-bit address space, 16-bit word-addressable (64K words)
  Harvard architecture: separate instruction and data memory

INSTRUCTION FORMATS (all 16 bits wide):
  
  R-type (register-register ALU):
    [15:12] opcode  [11:9] Rd  [8:6] Rs1  [5:3] Rs2  [2:0] func
    
  I-type (immediate ALU / load / store / branch offset):
    [15:12] opcode  [11:9] Rd  [8:6] Rs1  [5:0] imm6 (sign-extended)

  J-type (jump):
    [15:12] opcode  [11:0] imm12 (sign-extended, PC-relative)

OPCODES (4 bits):
  0x0  ALU    R-type   Rd = Rs1 <func> Rs2
  0x1  ADDI   I-type   Rd = Rs1 + sext(imm6)
  0x2  ANDI   I-type   Rd = Rs1 & zext(imm6)
  0x3  ORI    I-type   Rd = Rs1 | zext(imm6)
  0x4  LW     I-type   Rd = MEM[Rs1 + sext(imm6)]
  0x5  SW     I-type   MEM[Rs1 + sext(imm6)] = Rd
  0x6  BEQ    I-type   if (Rd == Rs1) PC += sext(imm6)
  0x7  BNE    I-type   if (Rd != Rs1) PC += sext(imm6)
  0x8  BLT    I-type   if (signed(Rd) < signed(Rs1)) PC += sext(imm6)
  0x9  JAL    J-type   R7 = PC+1; PC += sext(imm12)
  0xA  LUI    I-type   Rd = {imm6, 10'b0}  (load upper immediate)
  0xB  XORI   I-type   Rd = Rs1 ^ zext(imm6)
  0xC  SLTI   I-type   Rd = (signed(Rs1) < sext(imm6)) ? 1 : 0
  0xD  JALR   I-type   R7 = PC+1; PC = Rs1 + sext(imm6)
  0xE  SYS    I-type   System: imm6=0 → HALT
  0xF  (reserved)

ALU FUNC (3 bits, used when opcode=0x0):
  0  ADD    Rd = Rs1 + Rs2
  1  SUB    Rd = Rs1 - Rs2
  2  AND    Rd = Rs1 & Rs2
  3  OR     Rd = Rs1 | Rs2
  4  XOR    Rd = Rs1 ^ Rs2
  5  SLL    Rd = Rs1 << Rs2[3:0]
  6  SRL    Rd = Rs1 >> Rs2[3:0]  (logical)
  7  SLT    Rd = (signed(Rs1) < signed(Rs2)) ? 1 : 0
```
